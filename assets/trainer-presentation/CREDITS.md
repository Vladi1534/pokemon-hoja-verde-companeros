# Entrenadores y bicicleta

PNG originales de Pokémon FireRed/LeafGreen, publicados como datos de referencia por pret/pokefirered, commit ce6406d8c2eaf46d543c8a2606de0c3cb1951982.

Origen: `graphics/trainers/front_pics`, `graphics/trainers/back_pics` y `graphics/object_events/pics/people`. `scripts/import-trainer-presentation.cjs` guarda los bytes PNG sin modificar en `sprites.json`; `scripts/build-runtime.cjs` crea el paquete del navegador. La correspondencia numérica procede de `include/constants/trainers.h` y `src/data/graphics/trainers.h`.

Gráficos y personajes © Nintendo, GAME FREAK y The Pokémon Company. El proyecto es una adaptación fan. Este paquete no incluye una ROM.
