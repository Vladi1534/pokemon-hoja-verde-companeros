# Atribución de recursos de personajes

## Líderes y Alto Mando

Personajes y arte original de Pokémon: Nintendo / Game Freak / Creatures. Recursos mantenidos por la comunidad pret / rh-hideout.

Fuente: https://github.com/rh-hideout/pokeemerald-expansion/tree/f4dc700a130330fd2f9325a17bbb1e2d91dbf091/graphics/object_events/pics/people

Revisión fija: `f4dc700a130330fd2f9325a17bbb1e2d91dbf091`.

Archivos: Giovanni, Lt. Surge, Erika, Koga, Sabrina, Blaine, Lorelei, Bruno, Agatha y Lance. Los avisos y créditos adicionales upstream se conservan en `CREDITS-rhh.md`.

## Ash, Jessie y James

Adaptaciones comunitarias del mod HGSS Visual Overhaul de LucianoNeo/gen1recomp-mods. No se presentan como gráficos oficiales del anime ni como sprites originales de GBA.

Fuente: https://github.com/LucianoNeo/gen1recomp-mods/tree/768f60d9d0f097b9cc65e78099574c296a3f63d2/hgss_sprites/overrides/sprites

Revisión fija: `768f60d9d0f097b9cc65e78099574c296a3f63d2`.

La documentación upstream menciona el pack HGSS/DPP de Ash de PKMNTrainerRick para sprites de pesca. No se pudo atribuir individualmente la hoja HD actual de marcha de Ash, ni las hojas overworld actuales de Jessie y James. No se atribuyen a autores de otros recursos, como sus retratos de combate.

Personajes Pokémon: Nintendo / Game Freak / Creatures. No se encontró una licencia global explícita para el repositorio del mod en la revisión consultada. La disponibilidad pública del repositorio no se describe aquí como una licencia adicional para sus gráficos.

## Integridad

Los 13 PNG se conservan sin modificar. El manifiesto incluye sus URL de origen, revisión, dimensiones y SHA-256. Los archivos `people-additions.js` y `anime-additions.js` sólo los encapsulan en data URLs para el cargador de recursos del juego.
